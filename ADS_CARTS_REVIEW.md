# Исправление корзин рекламных кампаний

Ветка: fix/ads-carts-report. Основа: 3daaeca3fbb06b3e62fbe19c96e569c486d26e07 — рабочая версия с исправленной датой доставки, без Hogar Premium.

## Изменения

Ранее корзины распознавались только в ответе /api/client/statistics/daily/json. Дневной отчёт не гарантирует этот показатель. Добавлено отдельное read-only чтение /api/client/statistics/campaign/product/json за тот же диапазон dateFrom/dateTo. Число корзин связывается по ID кампании с имеющейся статистикой, а не прибавляется к дневным суммам. Остальные показатели из нового отчёта не используются и не дублируются.

Подтверждённый 0 сохраняется; пропуск или некорректное значение остаётся null/«—». Повторные кампании в ответе не суммируются. Кампании с корзинами, но без дневной строки, также могут отображать подтверждённые корзины. В сводке указано неполное покрытие. Конверсия клика в корзину рассчитывается только при наличии корзин и ненулевых кликов.

Если дополнительный отчёт недоступен, расходы, клики и заказы из дневного отчёта сохраняются. Диагностика показывает безопасный HTTP-статус и только имена полей, без секретов и сырого ответа. Повтор 401 обновляет Performance-токен один раз.

Не изменены: main, CORS, авторизация, дата доставки, заказы, «В пути», финансовые маршруты и их кеш. Новых API-маршрутов и операций изменения данных Ozon нет. Существующий кеш рекламы и его TTL сохранены.

## Проверки

- node --check server.js; синтаксис всех inline-скриптов frontend.
- node --test ads-carts.test.cjs: 5 групп тестов — соединение по кампании и периоду, ноль/пропуск, защита от повторного сложения, некорректные данные, ошибки 403/429/500, повтор 401.
- Интеграция DOM: карточки, сводка, частичное покрытие, конверсия, четыре периода, необязательный отчёт при 429, сохранность кеша финансов, только GET-запросы frontend. Команда: npm install --no-save --package-lock=false jsdom@30.1.3; node ads-carts-ui.cjs. jsdom нужен только для тестов.
- Участок server.js от deliveryDatesFromReport до конца файла побайтово не изменён относительно 3daaeca. Финансовая часть frontend не редактировалась.

## Что ещё требуется

Проверки выполнены на искусственных ответах, а не на живом кабинете. Фактическое наличие и формат поля корзин в текущем аккаунте Ozon нужно проверить после согласованного развёртывания. Если Ozon не отдаёт поле в этом отчёте, потребуется следующий этап диагностики/источник статистики. Не считать тесты подтверждением реального числа корзин.

Вход в Render в сессии истёк; проверить текущий Live-коммит и развернуть исправление без восстановления доступа невозможно. При подготовке изменений main и действующий Render не менялись. Отдельного разрешения на деплой этого исправления пока нет.
