# Ozon AI Assistant — прототип

В этом репозитории находятся две независимые демонстрационные части:

- `mobile_demo/index.html` — мобильный интерфейс, можно открыть в браузере без установки.
- `backend_demo/` — локальный Python/FastAPI-прототип с рекламой, расписаниями и аналитикой. Инструкции запуска: `backend_demo/README.md`.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и /(root). Для публикации мобильного демо через GitHub Pages удобнее перенести содержимое `mobile_demo/index.html` в корневой `index.html`. Альтернатива: после включения Pages откройте путь `/mobile_demo/index.html` на адресе Pages вашего репозитория.

## Важно

Данные вымышленные. Ozon API, Telegram, безопасная авторизация, резервные коды и рабочая запись цен не подключены. Нельзя размещать реальные ключи API в публичном репозитории. Прототип не готов к боевому использованию. Налоговая модель не подтверждена.
