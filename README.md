# Ozon AI Assistant — mobile UI v0.6

Откройте `index.html` в браузере (или опубликуйте как статический сайт). Это демонстрационный мобильный интерфейс: отдельные настройки кампаний, дневные/недельные лимиты, ставки, расписание и пример почасового графика. Данные вымышленные. Настройки сохраняются в localStorage конкретного браузера, не синхронизируются между устройствами.

**Не реализовано:** подключение к Ozon, реальная аналитика, облачная база, Telegram, фоновые задачи, реальные изменения ставок, авторизация.

План backend: FastAPI, PostgreSQL, фоновый worker, Ozon Performance API, Telegram Bot API. На первом этапе все операции только чтение; затем отдельный dry-run и ограниченное автоматическое применение после тестов.

## v0.7: Репрайсер с защитой прибыли

В мобильном демо добавлена форма фиксированной цены/диапазона и расчёт безопасного минимума. При цене ниже минимума расчёт поднимает её до безопасной; если безопасный минимум выше максимума диапазона, действие блокируется. При неизвестных расходах расчёт блокируется. Настройки формы сохраняются только в localStorage. Для реального автоприменения нужен сервер, учёт товара, подтверждённая модель затрат и Seller API Ozon. `repricer.js` содержит независимую функцию `safePrice`.
